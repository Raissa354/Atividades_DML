Atividade SQL – Consultas e Manipulação de Dados (DML)

Neste projeto, foram desenvolvidas consultas SQL utilizando o banco de dados vendas_informatica, com o objetivo de praticar a seleção e filtragem de informações em tabelas de produtos, clientes e vendas.

Foram utilizados comandos como SELECT, WHERE, LIKE, BETWEEN, IN, INNER JOIN e ORDER BY, além de operadores de comparação e filtros por períodos de datas.

As atividades envolveram consultas por datas de cadastro e vendas, buscas por nomes e marcas, identificação de formas de pagamento, relacionamento entre tabelas e ordenação de resultados por valores e status das vendas.

O objetivo foi desenvolver conhecimentos práticos em SQL, aprimorando a capacidade de consultar, relacionar, filtrar e organizar dados em um banco de dados relacional.
